# 🎮 Game Journal

**Личный журнал пройденных игр** — веб-приложение для домашней сети, где удобно вести
библиотеку пройденных игр с обложками, следить за тем, что проходишь сейчас, держать
очередь «хочу пройти» и решать, стоит ли закрывать игру на 100% достижений.

Написано на **Python + Flask + SQLite**. Работает на твоём компьютере, данные хранятся
локально в одном файле базы. Открывается с любого устройства в домашней сети — с ПК,
телефона или планшета.

> English summary: a self-hosted game completion tracker. Library with cover art, "now playing"
> and wishlist queues, Steam sync (playtime and achievements), and 100%-completion estimates
> based on HowLongToBeat and Steam achievement data. Python/Flask/SQLite, no accounts, runs on your LAN.

## Возможности

- 📚 **Библиотека пройденных игр** — сетка обложек, время, дата и процент прохождения,
  количество прохождений, заметки. Фильтры, поиск и сортировка.
- 🔍 **Поиск по каталогу игр** — подсказки при вводе, фильтры по жанру, году, отзывам и
  популярности; карточка игры с временем прохождения и сложностью 100%, добавление в нужный
  список одной кнопкой. Обложки и данные подтягиваются автоматически.
- ▶️ **Сейчас прохожу** — игры в процессе; кнопка «Пройдено ✓» переносит игру в библиотеку.
- ⭐ **Хочу пройти** — очередь с приоритетами, которую можно переставлять стрелками.
- 🎯 **Рекомендации** — игры, похожие на пройденные и хотелки: подбор по тегам Steam
  с учётом того, что ты перепроходил и оценил высоко.
- 🏆 **Оценка 100% достижений** — для хотелок считается автоматически по данным
  HowLongToBeat и Steam: интерес, гринд, время на 100% и итоговый вывод.
  Для пройденных игр ставишь своё впечатление.
- 🔄 **Синхронизация со Steam** — время в игре, достижения и **распознавание прохождения
  по финальному достижению**: точная дата прохождения, плашка «🏁 Сюжет пройден» и
  автоматическое добавление пройденных игр из аккаунта в библиотеку.
- 🗓 **Хронология** — пройденные игры по годам с суммарным временем.
- 📄 **Импорт из текстового файла** — если список пройденного уже ведётся в блокноте.
- 🌙 Тёмная тема, адаптивная вёрстка для телефона, работа без регистрации и облаков.

## Быстрый старт

### Вариант 1. Портативная версия — Python не нужен (Windows)

1. Открой страницу [**Releases**](https://github.com/WhiteHio/game-journal/releases/latest)
   и в разделе **Assets** скачай архив **`GameJournal-…-windows.zip`** (≈13 МБ).
   ⚠️ Не «Source code (zip)» — в нём только исходный код без Python.
2. Распакуй его в любую папку, например `D:\Games\GameJournal`.
3. Дважды щёлкни **`start.bat`** — сайт сам откроется в браузере.

Внутри архива уже лежит Python и все библиотеки, ничего устанавливать не нужно.
Окно с сервером должно оставаться открытым, пока пользуешься сайтом.
Остановить — `Ctrl+C` или просто закрыть окно.

> Windows может показать предупреждение «Windows защитила ваш компьютер» для файла,
> скачанного из интернета: нажми «Подробнее» → «Выполнить в любом случае».
> Не распаковывай в папки, куда нужны права администратора (например, `C:\Program Files`).

### Вариант 2. Из исходного кода (Windows)

Нужен **Python 3.11 или новее** — [python.org](https://www.python.org/downloads/),
при установке отметь **«Add python.exe to PATH»**.

1. Скачай код (**Code → Download ZIP**) и распакуй, или склонируй:
   ```bat
   git clone https://github.com/WhiteHio/game-journal.git
   ```
2. Дважды щёлкни **`start.bat`**. При первом запуске он создаст виртуальное окружение
   и установит библиотеки (около минуты); если `requirements.txt` изменится после обновления,
   недостающие библиотеки доустановятся сами.
3. Сайт откроется в браузере: **http://localhost:5000**.

### Вариант 3. Вручную (Windows, Linux, macOS)

```bash
python -m venv .venv
# Windows:
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python app.py
# Linux / macOS:
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python app.py
```

База данных `data/games.db` создаётся автоматически при первом запуске.
При обновлении до новой версии структура базы обновляется сама — данные сохраняются.

**Настройки запуска** (переменные окружения): `GAME_JOURNAL_PORT` — другой порт вместо 5000,
`GAME_JOURNAL_NO_BROWSER=1` — не открывать браузер при запуске.

## Вкладки и как ими пользоваться

### 🔍 Поиск (вкладка-лупа в меню)

Вкладка с лупой 🔍 в меню открывает поиск игр. Уже во время ввода выпадают **подсказки** — до 8 игр
с обложкой, годом и рейтингом (понимает начало слова: «cyberp», «hogw», «ведьм»);
стрелки ↑↓ и Enter открывают игру. Enter без выбора — сетка всех результатов из каталога
Steam (и RAWG, если указан ключ). Если игра уже есть у тебя, на обложке будет метка:
«✓ пройдена», «▶ прохожу» или «★ в хотелках».

**Фильтры** (кнопка «⚙ Фильтры» на странице поиска) работают и с названием, и без него —
можно просто подобрать игры по жанру:

- **жанр / тег** и ещё один тег — 400+ тегов Steam на русском («Глубокий сюжет»,
  «Открытый мир», «Хоррор», «Стелс»…);
- **год выхода** — с какого и по какой;
- **отзывы** — от 70/80/90% положительных;
- **популярность** — от 1 000 / 10 000 / 50 000 отзывов (без названия по умолчанию
  от 1 000, иначе в выдачу попадают тысячи безвестных игр);
- **сортировка** — по совпадению, сначала новые, по отзывам.

Клик по игре открывает **карточку-превью**:

- обложка, год, разработчик, жанры и описание;
- сколько достижений в Steam и насколько редкое самое редкое из них;
- время на сюжет и на 100% (HowLongToBeat), оценки интереса и гринда, итоговый вывод
  (подгружаются через несколько секунд);
- три кнопки: **✓ Пройдена**, **▶ Прохожу**, **★ Хочу пройти**.

Превью открывается и для игр, которые уже есть в твоих списках: видно, где игра у тебя и
твою статистику, а вместо кнопок добавления — «Открыть мою карточку». Так можно проверить,
стоит ли возвращаться к уже пройденной игре за 100%.

> Совет: если по-русски игра не находится, попробуй английское название.

### 📚 Библиотека

Главная страница — все пройденные игры.

- **Сверху статистика**: сколько игр пройдено, общее и среднее время, сколько игр на 100%
  достижений, сколько пройдено в текущем году.
- **Карточка-обложка** показывает процент прохождения (золотой значок — 100%), сколько раз
  игра пройдена (×2, ×3), время и дату прохождения.
- **Поиск по библиотеке** — по названию.
- **Фильтры**: «Все», «100%», «Перепроходил», текущий год.
- **Сортировка**: по дате прохождения, дате добавления, названию, времени, проценту.
- Кнопка **«+ Пройденная игра»** открывает быстрый поиск прямо в окне — нашёл, нажал
  «Добавить», заполнил статистику. Горячая клавиша — **`/`**.

### ▶️ Сейчас прохожу

Игры, которые проходишь прямо сейчас. Счётчик рядом с названием вкладки показывает,
сколько их.

- **«+ Начать игру»** — добавить игру из поиска; дата начала ставится сегодняшняя.
- В карточке такой игры: наиграно, дата начала, прогресс в процентах, заметка и оценка
  100% по данным из интернета (как у хотелок).
- **«Пройдено ✓»** — игра переезжает в библиотеку с сегодняшней датой прохождения
  (дату можно поправить). Если игра раньше уже была пройдена и ты её перепроходил,
  счётчик прохождений увеличится на 1.

### ⭐ Хочу пройти

Очередь на прохождение — **сверху то, что в приоритете**.

- **«+ В хотелки»** — добавить игру; она встаёт в конец очереди.
- Стрелки **↑ / ↓** меняют порядок.
- **«▶ Начать»** переносит игру в «Сейчас прохожу».
- Для каждой игры показано: время на сюжет и на 100%, интерес, гринд, сложность 100%
  по редкости достижений и итог — «Стоит закрыть на 100%», «На любителя» или
  «Больше гринда, чем удовольствия». Всё это считается автоматически,
  подробнее — в разделе [Оценка 100%](#оценка-стоит-ли-закрывать-на-100).

### 🎯 Рекомендации

Игры, которых у тебя ещё нет, подобранные под твой вкус.

**Как подбираются.** Для каждой твоей игры из Steam берутся пользовательские теги Steam
(«Открытый мир», «Сильный сюжет», «Стелс», «Хоррор»… — через [SteamSpy](https://steamspy.com)).
Из них складывается **профиль вкуса** — он показан вверху страницы, полоска у тега
показывает его вес. При этом:

- пройденные игры весят больше, чем хотелки и начатые;
- перепройденные, закрытые на 100% и высоко оценённые в «Моём впечатлении» — ещё больше,
  а оценённые низко — меньше;
- общие теги вроде «Одиночная игра» не учитываются — они ничего не говорят о вкусе.

Дальше по самым весомым тегам (и нескольким случайным из следующих) набираются популярные
игры с хорошими отзывами — от 3000 отзывов и от 75% положительных, — и каждая сравнивается
с профилем. При сортировке учитывается:

- **новизна** — играм последних лет небольшой бонус, совсем старым — небольшой штраф,
  иначе классика с сотнями тысяч отзывов вытесняет всё остальное;
- **прошлые показы** — игра, которую уже предлагали, при следующем обновлении опускается ниже,
  поэтому при каждом обновлении большая часть списка меняется;
- **немного случайности**, чтобы выдача не была одинаковой;
- **серии** — в выдаче не больше двух игр одной серии.

**Годы выхода** — фильтр вверху страницы: «любые годы», «с 2015 года» или «последние 5 лет».
При смене фильтра рекомендации пересчитываются.

**На карточке рекомендации**: процент совпадения со вкусом, доля положительных отзывов
в Steam, год выхода, на какие твои игры она похожа и общие теги. Кнопки:

- клик по обложке или названию — карточка-превью с временем прохождения и оценкой 100%;
- **★ Хочу** — добавить в «Хочу пройти»;
- **✕** — «не интересно», игра больше не будет предлагаться.

**⟳ Обновить рекомендации** запускает расчёт в фоне — страница показывает прогресс и
обновится сама. Обычно это около 30 секунд: теги и годы выхода кэшируются в базе, списки
игр по тегам — на 12 часов, годы выхода загружаются параллельно, а новых игр (их теги
SteamSpy отдаёт по одной в секунду) за одно обновление проверяется не больше 25 — с каждым
обновлением кэш растёт. Самый первый расчёт для большой библиотеки — пара минут.
Обновляй рекомендации, когда добавишь новые игры или захочешь увидеть другие варианты.

> Учитываются только игры, привязанные к Steam. Игры, добавленные вручную или через RAWG,
> в профиль вкуса не попадают.

### 🗓 Хронология

Пройденные игры, сгруппированные по годам прохождения, с количеством игр и суммарным
временем за год. Игры без даты — в группе «Без даты».

### 📥 Импорт

Если подключён Steam — здесь видны игры из твоего аккаунта, которых ещё нет на сайте
(отсортированы по наигранному времени). Сверху — **поиск по списку** и **⚙ Фильтры**, как во
вкладке поиска: жанр и второй тег, год выхода, отзывы, популярность и сортировка (по времени,
названию, новизне, отзывам). Фильтры работают на лету, без перезагрузки страницы.
У каждой игры две кнопки: **✓ Пройдена** — в библиотеку, **▶** — в «Прохожу».

Жанры, годы и отзывы берутся из кэша SteamSpy и Steam (общего с рекомендациями). При первом
открытии недостающее догружается в фоне — на странице видно, сколько осталось; для большой
библиотеки это минута-другая, дальше — мгновенно.

### ⚙️ Настройки

- **Ключ Steam Web API** и **профиль Steam** — для синхронизации (см. [Подключение Steam](#подключение-steam)).
- **Ключ RAWG** (необязательно) — добавляет в поиск игры, которых нет в Steam: консольные
  эксклюзивы, игры GOG, Epic и т.д. Бесплатно на [rawg.io/apidocs](https://rawg.io/apidocs).

### ⟳ Steam (кнопка в шапке)

Запускает синхронизацию со Steam. Занимает до минуты — Steam опрашивается по каждой игре.

## Карточка игры

Клик по любой игре открывает её карточку. Набор полей зависит от того, в каком списке игра.

| Поле | Пройдена | Прохожу | Хочу пройти |
|---|:---:|:---:|:---:|
| Название (можно переименовать) | ✓ | ✓ | ✓ |
| Время прохождения / наиграно | ✓ | ✓ | |
| Дата прохождения | ✓ | | |
| Дата начала | | ✓ | |
| Количество прохождений | ✓ | | |
| Процент прохождения / прогресс | ✓ | ✓ | |
| Моё впечатление о 100% (интерес, гринд, часы) | ✓ | | |
| Оценка 100% по данным из интернета | подсказка | ✓ | ✓ |
| Заметка, замена обложки | ✓ | ✓ | ✓ |

**Форматы времени**: `61 ч 24 мин`, `61:24`, `61.5` (часы), `61`, `2h 30m`.

**Кнопки**:

- **Сохранить**, **Отмена**, **Удалить игру** (с подтверждением);
- у пройденной игры — **↻ Перепройти**: игра возвращается в «Сейчас прохожу», а когда
  закончишь — добавится ещё одно прохождение;
- у начатой — **Пройдено ✓**;
- у хотелки — **▶ Начать проходить** и **⟳ Обновить оценку**;
- **«из Steam»** рядом с процентом — подставить процент полученных достижений Steam.

Если игра синхронизирована со Steam, слева под обложкой видно время в Steam, полученные
достижения и дату последнего из них, а если получено финальное достижение — плашка
**«🏁 Сюжет пройден 03.12.2024 — достижение «The World»»**.

Под карточкой игры из Steam — блок **«Финал игры»**: каким способом определяется
прохождение (см. [Распознавание прохождения](#распознавание-прохождения-по-достижениям))
и список всех достижений игры, где можно самому выбрать финальное — для игр, где финал
назван по последней миссии. Названия и описания достижений показываются по-русски
(из русской версии Steam), если у игры есть перевод; распознавание финала работает
по английским описаниям.

## Оценка «стоит ли закрывать на 100%»

Для игр из «Хочу пройти» и «Сейчас прохожу», а также в карточке-превью из поиска приложение само собирает
данные из интернета:

| Источник | Что берём |
|---|---|
| [HowLongToBeat](https://howlongtobeat.com) | время на сюжет и на 100%, рейтинг игроков, сколько из прошедших добили игру до 100% |
| Steam | число достижений, доля игроков с самым редким достижением, описания достижений (ищем «собери все», «убей 500», онлайн) |
| Metacritic (через Steam) | рейтинг игры, если его нет на HowLongToBeat |

Из этого считаются:

- **Гринд (1–5)** — во сколько раз 100% дольше сюжета; оценка выше, если много
  достижений на сбор и счётчики или есть онлайн-достижения (они зависят от других
  игроков и могут стать недоступны).
- **Интерес (1–5)** — насколько игра нравится людям и как часто её добивают до 100%.
- **Сложность 100%** — по доле игроков с самым редким достижением: если его получили 3%
  игроков, то 100% есть не больше чем у 3%. Легко (от 20%), средне (5–20%), сложно (1–5%),
  очень сложно (меньше 1%).
- **Итог**: «Стоит закрыть на 100%», «На любителя» или «Больше гринда, чем удовольствия».

В карточке игры видно, из чего сложилась оценка, например:
*«100% дольше сюжета в 3,9 раза (10 ч → 38 ч) · рейтинг HowLongToBeat: 84/100 ·
6% прошедших закрыли на 100% — добивают редко»*.

Для **пройденных** игр (вкладка «Библиотека») интерес, гринд и время на 100% ставишь ты сам — это твоё
впечатление. Оценка из интернета остаётся рядом как подсказка.

> Оценка из интернета — ориентир, а не истина: она отражает мнение и статистику других
> игроков. Данные кэшируются на несколько часов, обновить можно кнопкой «⟳ Обновить оценку».

## Подключение Steam

1. Получи бесплатный ключ: [steamcommunity.com/dev/apikey](https://steamcommunity.com/dev/apikey).
   В поле «Domain Name» можно написать `localhost`.
2. В Steam: **Профиль → Редактировать профиль → Приватность → «Сведения об играх» →
   «Открытые»**. Без этого Steam не отдаёт список игр.
3. На сайте: **Настройки** → вставь ключ и ссылку на профиль
   (`https://steamcommunity.com/id/имя` или `https://steamcommunity.com/profiles/7656…`) → Сохранить.
4. Нажми **⟳ Steam** в шапке.

Что делает синхронизация:

- обновляет время в Steam и полученные достижения у всех игр, привязанных к Steam;
- **заполняет только пустые поля**: время, процент (по достижениям) и — для пройденных
  игр — дату прохождения: точную, по финальному достижению, а если его нет — примерную,
  по последнему полученному. То, что ты ввёл сам, никогда не перезаписывается;
- **распознаёт прохождение** по финальному достижению (см. ниже) и **добавляет в библиотеку
  пройденные игры из аккаунта**, которых в ней ещё нет;
- загружает глобальную редкость достижений и досчитывает оценки 100% для хотелок.

Первая синхронизация после обновления занимает несколько минут — загружаются списки
достижений всех игр; дальше они берутся из кэша.

### Распознавание прохождения по достижениям

Steam не сообщает «игра пройдена», но во многих играх есть достижение за финал. Сайт ищет
его в списке достижений игры:

| Способ | Примеры | |
|---|---|---|
| явная формулировка | «Finish the game», «Complete the main storyline», «Komplete Story Mode», «Complete 100% of Story mode», «Finish the Campaign on any difficulty» | автоматически |
| последняя глава | «Complete Chapter 1 … 12», «Complete Act 4» — финал по последнему номеру | автоматически |
| выбор вручную | Mafia, Metro Exodus и др., где финал — «Complete the CASPIAN level» | в карточке игры, блок «Финал игры» |

Достижения за прохождение на разной сложности тоже подходят — берётся самое раннее
полученное. Не считаются: вступление и пролог, отдельные кампании и миссии, кооп и сетевые
режимы, частичное прохождение («50% сюжета»), DLC и New Game+.

Если финальное достижение получено:

- **пройденная игра без даты** получает точную дату прохождения;
- **игра в «Прохожу» или в хотелках** — плашку «🏁 сюжет пройден»; кнопка «Пройдено ✓»
  поставит дату финала, а не сегодняшнюю. Сама игра никуда не переносится — решаешь ты;
- **игра из аккаунта, которой нет в библиотеке** (наиграно от часа), добавляется
  в библиотеку как пройденная — с обложкой, датой финала и временем из Steam,
  с пометкой «Добавлена автоматически при синхронизации Steam». Если в библиотеке уже есть
  та же игра в другом издании (Enhanced, Definitive, Remastered…), дубль не создаётся.

Удалённую из библиотеки игру синхронизация больше не добавит сама. Если добавишь её
снова вручную — запрет снимется.

Ограничения: работает только для игр из Steam с открытым профилем и только по достижениям
этого аккаунта; в части игр понятного финального достижения нет — для них финал можно
указать вручную или отмечать прохождение как раньше.

> Ключ Steam хранится только в твоей локальной базе `data/games.db` и никуда, кроме Steam,
> не отправляется. Не публикуй файл базы — в нём лежит ключ.

**EA app, Epic Games, Ubisoft Connect** — эти платформы не предоставляют публичного API
для библиотеки и времени в играх, поэтому такие игры добавляются через поиск вручную.

## Импорт списка из текстового файла

Если список пройденного уже ведётся в блокноте, его можно загрузить разом:

```bat
.venv\Scripts\python import_txt.py "путь\к\списку.txt" --dry-run   :: только показать, что с чем сопоставится
.venv\Scripts\python import_txt.py "путь\к\списку.txt"             :: импортировать
```

В портативной версии вместо `.venv\Scripts\python` пиши `python\python.exe`.

Формат — по игре на строку, номер в начале необязателен:

```text
1.Red Dead Redemption 2
16.Max Payne 3 (перепройден 09.09.2026)
46.Mafia III(пройдена 17.01.2026)
92.Resident Evil 3 "100%"(22.03.2026)
93.Atomic Heart + 4 DLC "100%" (20.05.2026)
```

- дата `ДД.ММ.ГГГГ` → дата прохождения;
- «перепройден» → 2 прохождения;
- `"100%"` → процент прохождения;
- текст в скобках и «+ DLC …» → заметка;
- повторяющиеся игры объединяются, счётчик прохождений растёт.

Каждая строка сопоставляется с каталогом Steam, обложки скачиваются автоматически.
Сначала запусти с `--dry-run` и проверь сопоставление. Если какая-то игра нашлась неверно,
укажи её номер в Steam в словаре `_APPIDS` в начале `import_txt.py`
(номер — это число в адресе страницы игры: `store.steampowered.com/app/`**`1174180`**).
Повторный импорт не создаёт дубликатов.

## Доступ с телефона и других устройств

Сервер слушает всю домашнюю сеть. При запуске в окне видна строка вида
`С телефона и других устройств в сети: http://192.168.1.10:5000` — открой этот адрес на
телефоне, подключённом к тому же Wi-Fi.

Если не открывается — при первом запуске Windows спросит разрешение на доступ к сети:
разреши для **частных сетей** (или добавь правило для порта 5000 в брандмауэре).

> Приложение рассчитано на домашнюю сеть: в нём нет входа по паролю.
> Не открывай порт 5000 в интернет.

## Резервная копия и перенос

Все твои данные — это база `data/games.db` (игры, статистика, оценки, настройки, кэш) и
скачанные обложки `static/covers/`. Сайт умеет сохранять их сам:

- **⚙ Настройки → «Скачать резервную копию»** — один zip-архив с базой и обложками.
  Сохрани его в облако или на другой диск. В архиве есть ключ Steam API — не выкладывай его
  в открытый доступ.
- **«Восстановить из копии»** — выбери такой архив и поставь галочку подтверждения. Текущие
  данные будут заменены, но перед этим сайт сам сохранит их копию в `data/backups/`, так что
  откатиться можно всегда. Подходит и архив, сделанный старой версией сайта: структура базы
  обновится сама.
- **Ежедневная копия**: при каждом запуске сайт раз в день сам делает копию в `data/backups/`
  и хранит последние 7. Список копий с кнопками скачивания — там же, в настройках.

**Перенос на другой компьютер**: скачай резервную копию, поставь на новом компьютере
Game Journal и восстанови в нём эту копию.

**Обновление портативной версии**: скачай новый архив из Releases, распакуй в новую папку
и перенеси в неё из старой `data/` и `static/covers/` (или восстанови резервную копию).
Структура базы обновится сама.

> База работает в режиме WAL: рядом с `games.db` при работе сайта лежат файлы
> `games.db-wal` и `games.db-shm` — это нормально. Копируй базу вручную только при
> выключенном сайте, а лучше пользуйся кнопкой «Скачать резервную копию» — она делает
> целостную копию даже на работающем сайте.

## Устройство проекта

```text
game-journal/
├── app.py            # сервер Flask: все страницы и логика
├── db.py             # схема SQLite и автоматическое обновление структуры базы
├── backup.py         # резервные копии: скачать, восстановить, ежедневные
├── catalog.py        # поиск в Steam Store / RAWG, детали игр, обложки, редкость достижений
├── estimates.py      # оценка 100%: HowLongToBeat + достижения Steam
├── steam_sync.py     # синхронизация со Steam Web API
├── story.py          # распознавание прохождения по финальному достижению
├── library_meta.py   # жанры, годы и отзывы игр аккаунта для фильтров «Импорта»
├── recommend.py      # рекомендации: профиль вкуса по тегам Steam (SteamSpy)
├── import_txt.py     # импорт списка игр из текстового файла
├── build_portable.py # сборка портативной версии (Python внутри)
├── .github/workflows/release.yml  # автосборка архива для Releases
├── templates/        # HTML-шаблоны (Jinja2)
├── static/           # стили, скрипты, скачанные обложки
├── data/             # база данных (создаётся при запуске, в git не попадает)
├── requirements.txt  # зависимости Python
└── start.bat         # запуск для Windows
```

**Зависимости**: [Flask](https://flask.palletsprojects.com/), [requests](https://requests.readthedocs.io/),
[howlongtobeatpy](https://github.com/ScrappyCocco/HowLongToBeat-PythonAPI).

**Внешние сервисы**:

| Сервис | Для чего | Нужен ключ |
|---|---|---|
| Steam Store API | поиск игр, описание, обложки | нет |
| Steam Web API | библиотека, время, достижения | да, бесплатный |
| Steam global achievements | редкость достижений | нет |
| HowLongToBeat | время прохождения, статистика 100% | нет |
| RAWG | игры не из Steam | да, бесплатный, необязательно |
| SteamSpy | теги игр и отзывы для рекомендаций | нет |

Переменная окружения `GAME_JOURNAL_DB` позволяет указать другой файл базы — удобно для
тестов.

## Как выпустить новую версию (для автора)

Портативный архив собирается автоматически на серверах GitHub (GitHub Actions):

```bash
git tag v1.1
git push origin v1.1
```

Через 2–3 минуты на странице **Releases** появится версия `v1.1` с прикреплённым архивом
`GameJournal-v1.1-windows.zip`. Ход сборки видно на вкладке **Actions**.

Собрать архив у себя: `python build_portable.py --version v1.1` — результат в папке `dist/`.
Сборщик скачивает официальный «Windows embeddable package» Python с python.org, ставит в него
библиотеки из `requirements.txt` и упаковывает вместе с кодом. Личные данные (`data/`,
обложки, `import/`) в архив не попадают.

## Частые вопросы

**Обложка не та или её нет.** Открой карточку игры → «Заменить обложку» и загрузи картинку.

**Игры нет в поиске.** Попробуй английское название; для игр не из Steam добавь ключ RAWG
в настройках или нажми в окне добавления «Добавить вручную».

**Синхронизация Steam пишет, что не может получить список игр.** Проверь, что
«Сведения об играх» в приватности профиля — «Открытые», и что ключ указан верно.

**Синхронизация нашла не все игры.** Игры, пройденные на других платформах или купленные в
другом аккаунте, Steam не видит — время для них заполняется вручную.

**Не загружаются оценки HowLongToBeat.** У HowLongToBeat нет официального API, данные
получаются через библиотеку `howlongtobeatpy`. Если сайт HowLongToBeat поменялся,
обнови её: `.venv\Scripts\python -m pip install -U howlongtobeatpy`
(в портативной версии — скачай свежий архив из Releases).
Остальные функции продолжают работать.

**`start.bat` выдаёт ошибку при первом запуске.** Проверь, что Python установлен и команда
`py --version` работает в командной строке. Затем удали папку `.venv` и запусти снова.
