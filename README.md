# 🎮 Game Journal

**Личный журнал пройденных игр** — веб-приложение для домашней сети, где удобно вести
библиотеку пройденных игр с обложками, следить за тем, что проходишь сейчас, держать
очередь «хочу пройти» и решать, стоит ли закрывать игру на 100% достижений.

Написано на **Python + Flask + SQLite**. Работает на твоём компьютере, данные хранятся
локально в одном файле базы. Открывается с любого устройства в домашней сети — с ПК,
телефона или планшета.

> English summary: a self-hosted game completion tracker. Library with cover art, "now playing"
> and wishlist queues, Steam sync (playtime and achievements), and 100%-completion estimates
> based on HowLongToBeat and Steam achievement data. Python/Flask/SQLite, no accounts, runs on your LAN.

## Возможности

- 📚 **Библиотека пройденных игр** — сетка обложек, время, дата и процент прохождения,
  количество прохождений, заметки. Фильтры, поиск и сортировка.
- 🔍 **Поиск по каталогу игр** — находишь игру, смотришь её карточку (время прохождения,
  сложность 100%, описание) и одной кнопкой добавляешь в нужный список. Обложки и данные
  подтягиваются автоматически — ничего не нужно искать вручную.
- ▶️ **Сейчас прохожу** — игры в процессе; кнопка «Пройдено ✓» переносит игру в библиотеку.
- ⭐ **Хочу пройти** — очередь с приоритетами, которую можно переставлять стрелками.
- 🏆 **Оценка 100% достижений** — для хотелок считается автоматически по данным
  HowLongToBeat и Steam: интерес, гринд, время на 100% и итоговый вывод.
  Для пройденных игр ставишь своё впечатление.
- 🔄 **Синхронизация со Steam** — время в игре, полученные достижения, дата последнего
  достижения, импорт игр из аккаунта.
- 🗓 **Хронология** — пройденные игры по годам с суммарным временем.
- 📄 **Импорт из текстового файла** — если список пройденного уже ведётся в блокноте.
- 🌙 Тёмная тема, адаптивная вёрстка для телефона, работа без регистрации и облаков.

## Быстрый старт

### Что нужно

- **Windows 10/11** (на Linux/macOS тоже работает — см. ниже);
- **Python 3.11 или новее** — скачать на [python.org](https://www.python.org/downloads/).
  При установке отметь галочку **«Add python.exe to PATH»**;
- интернет — для поиска игр, обложек и данных Steam/HowLongToBeat.

### Запуск на Windows

1. Скачай проект (кнопка **Code → Download ZIP** на GitHub) и распакуй, или склонируй:
   ```bat
   git clone https://github.com/ArtyomT68/game-journal.git
   ```
2. Дважды щёлкни **`start.bat`**.
   При первом запуске он сам создаст виртуальное окружение и установит зависимости
   (около минуты). Следующие запуски — мгновенные.
3. Открой в браузере **http://localhost:5000**.

Окно с сервером должно оставаться открытым, пока пользуешься сайтом. Остановить — `Ctrl+C`
или просто закрыть окно.

### Запуск вручную (Windows, Linux, macOS)

```bash
python -m venv .venv
# Windows:
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python app.py
# Linux / macOS:
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python app.py
```

База данных `data/games.db` создаётся автоматически при первом запуске.
При обновлении проекта до новой версии структура базы обновляется сама — данные сохраняются.

## Вкладки и как ими пользоваться

### 🔍 Поиск (поле «Найти игру…» в шапке)

Поле поиска есть на любой странице. Введи название и нажми Enter — откроется сетка
результатов из каталога Steam (и RAWG, если указан ключ). Если игра уже есть у тебя,
на обложке будет метка: «✓ пройдена», «▶ прохожу» или «★ в хотелках».

Клик по игре открывает **карточку-превью**:

- обложка, год, разработчик, жанры и описание;
- сколько достижений в Steam и насколько редкое самое редкое из них;
- время на сюжет и на 100% (HowLongToBeat), оценки интереса и гринда, итоговый вывод
  (подгружаются через несколько секунд);
- три кнопки: **✓ Пройдена**, **▶ Прохожу**, **★ Хочу пройти**.

Превью открывается и для игр, которые уже есть в твоих списках: видно, где игра у тебя и
твою статистику, а вместо кнопок добавления — «Открыть мою карточку». Так можно проверить,
стоит ли возвращаться к уже пройденной игре за 100%.

> Совет: если по-русски игра не находится, попробуй английское название.

### 📚 Библиотека

Главная страница — все пройденные игры.

- **Сверху статистика**: сколько игр пройдено, общее и среднее время, сколько игр на 100%
  достижений, сколько пройдено в текущем году.
- **Карточка-обложка** показывает процент прохождения (золотой значок — 100%), сколько раз
  игра пройдена (×2, ×3), время и дату прохождения.
- **Поиск по библиотеке** — по названию.
- **Фильтры**: «Все», «100%», «Перепроходил», текущий год.
- **Сортировка**: по дате прохождения, дате добавления, названию, времени, проценту.
- Кнопка **«+ Пройденная игра»** открывает быстрый поиск прямо в окне — нашёл, нажал
  «Добавить», заполнил статистику. Горячая клавиша — **`/`**.

### ▶️ Сейчас прохожу

Игры, которые проходишь прямо сейчас. Счётчик рядом с названием вкладки показывает,
сколько их.

- **«+ Начать игру»** — добавить игру из поиска; дата начала ставится сегодняшняя.
- В карточке такой игры: наиграно, дата начала, прогресс в процентах, заметка и оценка
  100% по данным из интернета (как у хотелок).
- **«Пройдено ✓»** — игра переезжает в библиотеку с сегодняшней датой прохождения
  (дату можно поправить). Если игра раньше уже была пройдена и ты её перепроходил,
  счётчик прохождений увеличится на 1.

### ⭐ Хочу пройти

Очередь на прохождение — **сверху то, что в приоритете**.

- **«+ В хотелки»** — добавить игру; она встаёт в конец очереди.
- Стрелки **↑ / ↓** меняют порядок.
- **«▶ Начать»** переносит игру в «Сейчас прохожу».
- Для каждой игры показано: время на сюжет и на 100%, интерес, гринд, сложность 100%
  по редкости достижений и итог — «Стоит закрыть на 100%», «На любителя» или
  «Больше гринда, чем удовольствия». Всё это считается автоматически,
  подробнее — в разделе [Оценка 100%](#оценка-стоит-ли-закрывать-на-100).

### 🗓 Хронология

Пройденные игры, сгруппированные по годам прохождения, с количеством игр и суммарным
временем за год. Игры без даты — в группе «Без даты».

### 📥 Импорт

Если подключён Steam — здесь видны игры из твоего аккаунта, которых ещё нет на сайте
(отсортированы по наигранному времени). Кнопка «Добавить» добавляет игру в библиотеку.

### ⚙️ Настройки

- **Ключ Steam Web API** и **профиль Steam** — для синхронизации (см. [Подключение Steam](#подключение-steam)).
- **Ключ RAWG** (необязательно) — добавляет в поиск игры, которых нет в Steam: консольные
  эксклюзивы, игры GOG, Epic и т.д. Бесплатно на [rawg.io/apidocs](https://rawg.io/apidocs).

### ⟳ Steam (кнопка в шапке)

Запускает синхронизацию со Steam. Занимает до минуты — Steam опрашивается по каждой игре.

## Карточка игры

Клик по любой игре открывает её карточку. Набор полей зависит от того, в каком списке игра.

| Поле | Пройдена | Прохожу | Хочу пройти |
|---|:---:|:---:|:---:|
| Название (можно переименовать) | ✓ | ✓ | ✓ |
| Время прохождения / наиграно | ✓ | ✓ | |
| Дата прохождения | ✓ | | |
| Дата начала | | ✓ | |
| Количество прохождений | ✓ | | |
| Процент прохождения / прогресс | ✓ | ✓ | |
| Моё впечатление о 100% (интерес, гринд, часы) | ✓ | | |
| Оценка 100% по данным из интернета | подсказка | ✓ | ✓ |
| Заметка, замена обложки | ✓ | ✓ | ✓ |

**Форматы времени**: `61 ч 24 мин`, `61:24`, `61.5` (часы), `61`, `2h 30m`.

**Кнопки**:

- **Сохранить**, **Отмена**, **Удалить игру** (с подтверждением);
- у пройденной игры — **↻ Перепройти**: игра возвращается в «Сейчас прохожу», а когда
  закончишь — добавится ещё одно прохождение;
- у начатой — **Пройдено ✓**;
- у хотелки — **▶ Начать проходить** и **⟳ Обновить оценку**;
- **«из Steam»** рядом с процентом — подставить процент полученных достижений Steam.

Если игра синхронизирована со Steam, слева под обложкой видно время в Steam, полученные
достижения и дату последнего из них.

## Оценка «стоит ли закрывать на 100%»

Для игр из «Хочу пройти» и «Сейчас прохожу», а также в карточке-превью из поиска приложение само собирает
данные из интернета:

| Источник | Что берём |
|---|---|
| [HowLongToBeat](https://howlongtobeat.com) | время на сюжет и на 100%, рейтинг игроков, сколько из прошедших добили игру до 100% |
| Steam | число достижений, доля игроков с самым редким достижением, описания достижений (ищем «собери все», «убей 500», онлайн) |
| Metacritic (через Steam) | рейтинг игры, если его нет на HowLongToBeat |

Из этого считаются:

- **Гринд (1–5)** — во сколько раз 100% дольше сюжета; оценка выше, если много
  достижений на сбор и счётчики или есть онлайн-достижения (они зависят от других
  игроков и могут стать недоступны).
- **Интерес (1–5)** — насколько игра нравится людям и как часто её добивают до 100%.
- **Сложность 100%** — по доле игроков с самым редким достижением: если его получили 3%
  игроков, то 100% есть не больше чем у 3%. Легко (от 20%), средне (5–20%), сложно (1–5%),
  очень сложно (меньше 1%).
- **Итог**: «Стоит закрыть на 100%», «На любителя» или «Больше гринда, чем удовольствия».

В карточке игры видно, из чего сложилась оценка, например:
*«100% дольше сюжета в 3,9 раза (10 ч → 38 ч) · рейтинг HowLongToBeat: 84/100 ·
6% прошедших закрыли на 100% — добивают редко»*.

Для **пройденных** игр (вкладка «Библиотека») интерес, гринд и время на 100% ставишь ты сам — это твоё
впечатление. Оценка из интернета остаётся рядом как подсказка.

> Оценка из интернета — ориентир, а не истина: она отражает мнение и статистику других
> игроков. Данные кэшируются на несколько часов, обновить можно кнопкой «⟳ Обновить оценку».

## Подключение Steam

1. Получи бесплатный ключ: [steamcommunity.com/dev/apikey](https://steamcommunity.com/dev/apikey).
   В поле «Domain Name» можно написать `localhost`.
2. В Steam: **Профиль → Редактировать профиль → Приватность → «Сведения об играх» →
   «Открытые»**. Без этого Steam не отдаёт список игр.
3. На сайте: **Настройки** → вставь ключ и ссылку на профиль
   (`https://steamcommunity.com/id/имя` или `https://steamcommunity.com/profiles/7656…`) → Сохранить.
4. Нажми **⟳ Steam** в шапке.

Что делает синхронизация:

- обновляет время в Steam и полученные достижения у всех игр, привязанных к Steam;
- **заполняет только пустые поля**: время, процент (по достижениям) и — для пройденных
  игр — дату прохождения (по последнему полученному достижению). То, что ты ввёл сам,
  никогда не перезаписывается;
- загружает глобальную редкость достижений и досчитывает оценки 100% для хотелок.

> Ключ Steam хранится только в твоей локальной базе `data/games.db` и никуда, кроме Steam,
> не отправляется. Не публикуй файл базы — в нём лежит ключ.

**EA app, Epic Games, Ubisoft Connect** — эти платформы не предоставляют публичного API
для библиотеки и времени в играх, поэтому такие игры добавляются через поиск вручную.

## Импорт списка из текстового файла

Если список пройденного уже ведётся в блокноте, его можно загрузить разом:

```bat
.venv\Scripts\python import_txt.py "путь\к\списку.txt" --dry-run   :: только показать, что с чем сопоставится
.venv\Scripts\python import_txt.py "путь\к\списку.txt"             :: импортировать
```

Формат — по игре на строку, номер в начале необязателен:

```text
1.Red Dead Redemption 2
16.Max Payne 3 (перепройден 09.09.2026)
46.Mafia III(пройдена 17.01.2026)
92.Resident Evil 3 "100%"(22.03.2026)
93.Atomic Heart + 4 DLC "100%" (20.05.2026)
```

- дата `ДД.ММ.ГГГГ` → дата прохождения;
- «перепройден» → 2 прохождения;
- `"100%"` → процент прохождения;
- текст в скобках и «+ DLC …» → заметка;
- повторяющиеся игры объединяются, счётчик прохождений растёт.

Каждая строка сопоставляется с каталогом Steam, обложки скачиваются автоматически.
Сначала запусти с `--dry-run` и проверь сопоставление. Если какая-то игра нашлась неверно,
укажи её номер в Steam в словаре `_APPIDS` в начале `import_txt.py`
(номер — это число в адресе страницы игры: `store.steampowered.com/app/`**`1174180`**).
Повторный импорт не создаёт дубликатов.

## Доступ с телефона и других устройств

Сервер слушает всю домашнюю сеть. При запуске в окне видна строка вида
`Running on http://192.168.1.10:5000` — открой этот адрес на телефоне, подключённом к
тому же Wi-Fi. Узнать IP компьютера можно командой `ipconfig`.

Если не открывается — при первом запуске Windows спросит разрешение на доступ к сети:
разреши для **частных сетей** (или добавь правило для порта 5000 в брандмауэре).

> Приложение рассчитано на домашнюю сеть: в нём нет входа по паролю.
> Не открывай порт 5000 в интернет.

## Резервная копия и перенос

Все твои данные — это:

- `data/games.db` — база (игры, статистика, настройки);
- `static/covers/` — скачанные обложки.

Скопируй их в облако или на другой диск — это и есть резервная копия. Для переноса на
другой компьютер скопируй всю папку проекта, **кроме `.venv`** (окружение создаётся заново
при первом запуске `start.bat`).

## Устройство проекта

```text
game-journal/
├── app.py            # сервер Flask: все страницы и логика
├── db.py             # схема SQLite и автоматическое обновление структуры базы
├── catalog.py        # поиск в Steam Store / RAWG, детали игр, обложки, редкость достижений
├── estimates.py      # оценка 100%: HowLongToBeat + достижения Steam
├── steam_sync.py     # синхронизация со Steam Web API
├── import_txt.py     # импорт списка игр из текстового файла
├── templates/        # HTML-шаблоны (Jinja2)
├── static/           # стили, скрипты, скачанные обложки
├── data/             # база данных (создаётся при запуске, в git не попадает)
├── requirements.txt  # зависимости Python
└── start.bat         # запуск для Windows
```

**Зависимости**: [Flask](https://flask.palletsprojects.com/), [requests](https://requests.readthedocs.io/),
[howlongtobeatpy](https://github.com/ScrappyCocco/HowLongToBeat-PythonAPI).

**Внешние сервисы**:

| Сервис | Для чего | Нужен ключ |
|---|---|---|
| Steam Store API | поиск игр, описание, обложки | нет |
| Steam Web API | библиотека, время, достижения | да, бесплатный |
| Steam global achievements | редкость достижений | нет |
| HowLongToBeat | время прохождения, статистика 100% | нет |
| RAWG | игры не из Steam | да, бесплатный, необязательно |

Переменная окружения `GAME_JOURNAL_DB` позволяет указать другой файл базы — удобно для
тестов.

## Частые вопросы

**Обложка не та или её нет.** Открой карточку игры → «Заменить обложку» и загрузи картинку.

**Игры нет в поиске.** Попробуй английское название; для игр не из Steam добавь ключ RAWG
в настройках или нажми в окне добавления «Добавить вручную».

**Синхронизация Steam пишет, что не может получить список игр.** Проверь, что
«Сведения об играх» в приватности профиля — «Открытые», и что ключ указан верно.

**Синхронизация нашла не все игры.** Игры, пройденные на других платформах или купленные в
другом аккаунте, Steam не видит — время для них заполняется вручную.

**Не загружаются оценки HowLongToBeat.** У HowLongToBeat нет официального API, данные
получаются через библиотеку `howlongtobeatpy`. Если сайт HowLongToBeat поменялся,
обнови её: `.venv\Scripts\python -m pip install -U howlongtobeatpy`.
Остальные функции продолжают работать.

**`start.bat` выдаёт ошибку при первом запуске.** Проверь, что Python установлен и команда
`py --version` работает в командной строке. Затем удали папку `.venv` и запусти снова.
